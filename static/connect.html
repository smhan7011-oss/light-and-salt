스마트스토어 연결

이 컴퓨터에서 네이버 커머스 API를 호출합니다. API센터에 등록한 공인 IP와 현재 인터넷 회선이 같아야 합니다.

1. 인증 정보 설정

발급된 원문을 이 화면에만 입력하세요. 외부 AI 서비스에는 전달하지 않습니다.



2. 스토어 정보 조회
출고지·반품지는 네이버에 저장된 주소를 조회해서 사용합니다. 조회 결과에는 개인정보가 있으므로 그대로 공유하지 마세요.


3. 상품 이미지 업로드
대표 이미지와 제작한 상세페이지 PNG를 각각 업로드한 뒤 반환된 URL을 상품 데이터에 사용하세요. 상세 이미지 업로드만으로 상품이 등록되지는 않습니다.


4. 상품 등록 · 고급 설정
현재 상품 입력은 커머스 API JSON 방식입니다. 아래 예시에서 빈 항목과 카테고리별 필수 정보를 채워주세요. 자동완성되지 않으며, 실제 등록 검증은 네이버 서버가 수행합니다. 첫 상품은 전시중지 상태로 등록하여 판매자센터에서 확인합니다.
상세설명에는 업로드한 상세페이지 URL을 순서대로 <img src="https://…"> 형태로 넣습니다. 배송비는 4,000원이며, 반품·교환비는 실제 정책에 맞게 입력하세요.
API 실계정 연결과 등록은 아직 검증되지 않았습니다. 오류가 나면 인증 정보 대신 오류 메시지만 전달해주세요. 등록 중 연결이 끊기면 판매자센터를 확인하여 중복 등록을 방지하세요.
