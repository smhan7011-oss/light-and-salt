04 · SMARTSTORE

스마트스토어 등록

API 연결 및 상품 등록 화면 열기

Windows 로컬 서버에서 인증 정보를 설정한 뒤 연결하세요. 실계정 검증은 아직 수행하지 않았습니다.

실제 등록에는 카테고리, 재고, 상품정보제공고시, 배송·반품 설정과 커머스 API 인증이 필요합니다. 판매자센터 로그인 링크만으로 자동 등록할 수는 없습니다. 인증 정보는 채팅이나 이 화면에 입력하지 마세요.

제품 정보는 서버에 업로드하지 않고 현재 브라우저에서만 처리합니다. 새로고침하면 입력이 초기화됩니다.
