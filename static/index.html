상품 사진 → API 자동 분석 → 구성안 확인 → 낱장 이미지
01 · PRODUCT

상품 정보

기본 방식: 상품명·가격 입력 → 사진 선택 → AI API로 소구점·제품 정보 분석 → 내용 확인 → 상세페이지 제작. 분석 시 OpenAI API 사용료가 발생합니다.
AI API 연결 설정

사진에서 소구점과 라벨 정보를 읽어 자동 입력합니다. OpenAI API 키가 필요하며 사용료는 ChatGPT 구독과 별도입니다. 분석할 때 선택한 상품 사진과 상품명만 OpenAI로 전송합니다.

OpenAI API 키 발급 · 키는 채팅에 보내지 마세요. 네이버 시크릿과 다른 키입니다.

채팅 결과 가져오기 · 대체 방식

채팅에서 받은 ‘프로그램 가져오기용 JSON’ 전체를 붙여넣으세요. 소구점·제품 정보와 페이지별 문구를 한 번에 적용합니다. 사진은 아래에서 직접 선택해주세요.

원본의 색상·형태·로고를 바꾸지 않고 비율을 유지합니다. 대표 사진은 정면 사진을 선택하세요. 라벨 사진은 정보 확인에 사용하며 대표 사진과 구분합니다.

사진 편집 · 상품 중심으로 정리

AI 분석 후 상품 여백 정리 크롭이 추천됩니다. 미리보기에서 제품·라벨이 잘리지 않았는지 확인하세요. 복잡한 배경은 자동 제거하지 않습니다.

책상·손·복잡한 배경을 정확히 지우는 기능은 아닙니다. 제품 일부까지 지워지면 해제하세요.

AI 초안과 사진 근거

배송비 4,000원 · 출고지와 반품지는 API 연결 후 저장된 주소를 선택합니다.

02 · SELLING POINTS

핵심 소구점 3가지

사진을 선택하면 AI API로 분석한 소구점이 자동 입력됩니다. 채팅 결과 가져오기도 선택할 수 있습니다. 근거가 부족하면 추가 사진 또는 직접 입력이 필요합니다. 비교 우위나 확인되지 않은 효능은 작성하지 않습니다.

03 · STORYBOARD

제작 전 구성안

제품명과 핵심 소구점은 입력한 문구 그대로 사용합니다. 확인되지 않은 후기·평점·인증·비교 정보는 생성하지 않습니다.

왼쪽에 상품 정보와 사진을 넣으면 페이지별 문구, 이미지와 배치를 확인할 수 있습니다.

상세페이지 이미지

미리보기와 다운로드는 동일한 PNG 파일입니다. 스마트스토어에는 최종 확인 후 사용하세요.

04 · SMARTSTORE

스마트스토어 등록

API 연결 및 상품 등록 화면 열기

Windows 로컬 서버에서 인증 정보를 설정한 뒤 연결하세요. 실계정 검증은 아직 수행하지 않았습니다.

실제 등록에는 카테고리, 재고, 상품정보제공고시, 배송·반품 설정과 커머스 API 인증이 필요합니다. 판매자센터 로그인 링크만으로 자동 등록할 수는 없습니다. 네이버 인증 정보는 API 연결 화면에서만 입력하고 채팅에는 보내지 마세요.

상세페이지 제작은 브라우저에서 처리합니다. AI 분석을 실행할 때만 사진·상품명을 로컬 서버를 통해 OpenAI에 전송합니다. 사진은 앱 서버에 저장하지 않습니다. 새로고침하면 상품 입력은 초기화됩니다.
