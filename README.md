# 빛과 소금 · 상세페이지 & 스마트스토어 도구

## Windows 시작 방법

1. Python 공식 사이트 https://www.python.org/downloads/windows/ 에서 Python 3.12 이상을 설치합니다. 설치 시 Python Launcher도 포함하세요.
2. ZIP을 폴더에 **모두 압축 해제**합니다. ZIP 안에서 실행하지 마세요.
3. `start-windows.bat`을 더블클릭합니다. 첫 실행 때 가상환경과 bcrypt 의존성을 설치하므로 인터넷 연결이 필요합니다.
4. 브라우저가 열리면 ‘API 연결 및 상품 등록 화면 열기’를 누릅니다. 서버 창을 닫으면 프로그램이 종료됩니다.
5. 커머스API센터에서 발급한 애플리케이션 ID와 시크릿을 입력하고 ‘저장 및 연결 확인’을 누릅니다. API센터에 등록한 공인 IP와 이 컴퓨터가 사용하는 인터넷 회선의 공인 IP가 같아야 합니다.

**이 배포본은 Python 기반 Windows 실행 도구(.bat)이며 단독 실행형 .exe는 아닙니다.** 현재 Linux에서 검증했고 Windows 실제 실행과 실계정 API 연결은 아직 검증하지 않았습니다.

## 인증 정보

네이버 인증 서명을 서버에서 bcrypt로 생성하고 SELF 유형의 토큰을 요청합니다. 인증 정보는 브라우저 저장소나 소스 파일에 넣지 않습니다. 저장을 선택하면 Windows DPAPI로 암호화한 파일을 `%LOCALAPPDATA%\LightAndSaltStudio\credentials.bin`에 보관합니다. 동일한 Windows 사용자 계정에서 사용하세요. ‘인증 정보 삭제’는 파일과 현재 메모리의 인증을 삭제합니다. 네이버에서 이미 발급된 토큰의 원격 폐기를 의미하지는 않습니다.

시크릿을 채팅·저장소에 공유하지 마세요. 서버는 127.0.0.1에만 바인딩하고 Host/Origin/CSRF를 검사합니다. 웹에 직접 공개하는 서버가 아닙니다. Windows 외에는 영구 저장을 지원하지 않으며 ‘암호화하여 저장’을 해제하고 메모리에서만 시험할 수 있습니다.

## 상세페이지

상품명·가격·원본 사진·확인된 소구점 3가지를 입력하고 구성안을 검토한 뒤 이미지 제작을 누릅니다. 각 PNG는 860×1100이고 ZIP에 미리보기와 같은 PNG가 들어갑니다. 제품 사진은 비율을 유지하고 변형하지 않습니다. AI 사진 생성·자동 제품 분석·자동 소구점 작성은 아직 구현하지 않았습니다. 입력 내용은 브라우저 메모리에서만 처리되고 새로고침하면 지워집니다. 내려받은 결과를 보관하세요.

## 커머스 API 기능과 한계

- 인증 및 스토어 채널 조회: `/v1/oauth2/token`, `/v1/seller/channels`
- 주소·카테고리 조회: `/v1/seller/addressbooks`, `/v1/categories`
- 원본/상세페이지 이미지 업로드: `/v1/product-images/upload`
- 상품 등록: `/v2/products`

상품 등록은 현재 **고급 JSON 입력 방식**입니다. 일반 사용자를 위한 카테고리별 입력 폼·주소 선택 드롭다운·상세페이지 자동 업로드/연결은 아직 없습니다. 예시는 빈칸을 채우지 않고 등록할 수 없습니다. 실제 카테고리에 맞는 상품정보제공고시, 원산지, A/S, 배송사 코드, 출고지·반품지 ID, 배송비 정책 등을 네이버 규격에 맞게 작성해야 합니다. 모든 API 필수 항목을 로컬에서 검증하지 않으며 네이버가 최종 검증합니다.

첫 등록은 `smartstoreChannelProduct.channelProductDisplayStatusType`을 `SUSPENSION`(전시중지)으로만 허용합니다. 등록된 상품을 판매자센터에서 확인한 뒤 직접 전시 설정하세요. 기본 배송비는 4,000원으로 검사합니다. 반품비·교환비는 사용자의 실제 정책을 입력하세요. 인증만 연결했다고 스토어에 저장된 배송/반품 설정이 상품 등록 JSON에 자동 적용되지는 않습니다.

‘입력값 검토’는 네이버에 상품을 생성하지 않습니다. 검토한 내용을 보고 ‘상품 등록’ 확인 문구를 입력한 후 실제 등록 버튼을 눌러야 생성 요청을 보냅니다. 각 검토 티켓은 한 번만 사용하며 자동 재시도하지 않습니다. 등록 요청 중 오류나 시간 초과가 나면 판매자센터에서 생성 여부를 확인한 뒤 재시도하세요. 사진 업로드는 해당 버튼을 누를 때 즉시 수행됩니다.

## 개발 및 검증

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --port 8000
.venv/bin/python -m unittest discover -s tests -v
```

Windows에서는 `.venv\Scripts\python.exe`를 사용합니다. 서명/토큰 캐시, 오류 정보 제한, CSRF 차단, 검토 후 1회 등록 테스트를 포함합니다. 외부 등록 테스트는 mock 사용이며 실제 상품을 만들지 않습니다. Linux Chromium으로 이미지 제작, ZIP 무결성, 인증 화면 및 최종 확인 동작을 검증했습니다. Windows DPAPI, 네이버 실계정 권한·주소·이미지 업로드·상품 등록은 사용자의 컴퓨터에서 별도로 검증해야 합니다.
